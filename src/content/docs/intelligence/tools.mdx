This reference is generated from the application's tool registry. Expand an input schema to inspect the accepted fields before building an integration or debugging a request.

**Registration does not guarantee availability in your workspace.** Tool packs, module settings, provider readiness, and policy affect which tools an assistant can use. Check the tool's connection requirement and your [Setup Center](/docs/workspace/setup).

Read tools retrieve context. Tools that propose changes route through the [approval workflow](/docs/command-center/approvals). A proposal is not a completed external action.

Use the docs search above to find an exact tool name. For client setup, see [Connect an MCP client](/docs/extend/mcp-clients).

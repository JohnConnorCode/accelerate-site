Command Center lets a team work with customer records, conversations, opportunities, tasks and proposed AI actions in one application. Use these guides to complete a task or understand a result.

## Try a workflow

Open the [fictional demo](/demo/command-center) and follow [your first workflow](/docs/start/daily-path). You will find an item on Today, review an action and check its result. The demo needs no account or provider credentials.

## Do your work

| Task                            | Guide                                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| Decide what needs attention     | [Work the Today queue](/docs/command-center/today)                                           |
| Respond to a customer           | [Reply to a conversation](/docs/conversations/reply)                                         |
| Qualify a new inquiry           | [Review leads and chat handoffs](/docs/sources/leads)                                        |
| Update a deal and its next step | [Use the pipeline board](/docs/pipeline/board)                                               |
| Bring in existing contacts      | [Import contacts](/docs/contacts/import)                                                     |
| Review a proposed change        | [Approvals](/docs/command-center/approvals)                                                  |
| Understand a number             | [Revenue figures](/docs/pipeline/revenue)                                                    |
| Investigate a change or failure | [Activity](/docs/command-center/activity) and [Troubleshooting](/docs/start/troubleshooting) |

These guides describe the current application. The features available to you depend on your workspace, permissions, enabled modules and connections. Use [Setup Center](/docs/workspace/setup) to check your installation.

## Set up or extend a workspace

- **Business owners:** [choose a workflow and assign responsibility](/docs/start/business-owners).
- **Agencies:** [prepare a client workspace and hand it over](/docs/start/agencies).
- **Developers:** [run the app and make a first change](/docs/extend/first-change).
- **Self-hosters:** [install with your own database and accounts](/docs/self-hosting/installation).

For unfamiliar terms, use [Core concepts](/docs/start/core-concepts). For an action that has already run, use [Action results](/docs/start/receipts) to distinguish approval, execution and delivery.

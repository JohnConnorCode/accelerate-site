By the end of this guide, you will know how to find work on Today, inspect a suggested action, and check what happened after your decision.

**You need:** a browser. Use the [Command Center demo](/demo/command-center), choose a fictional business, and open its workspace. Demo actions are simulated; they do not send messages or change a real business.

## 1. Find what needs you

Open **Today** in the workspace navigation. The priority queue brings together replies, commitments, proposals, and approvals. Read an item's reason and next action before opening it.

## 2. Inspect a proposed action

Choose **Review** on an approval item. Check who or what the action affects, the proposed change, and the context supporting it. For an email, read the recipient, subject, and complete message.

An action being suggested does not mean it has already happened.

## 3. Make a decision

Approve an action you agree with. If the content needs work, edit it and review the revised version before approving. Reject a suggestion you do not want to run.

In the demo, this changes fictional browser state only. In a connected workspace, approving a send can deliver a real message. Read the confirmation before continuing.

## 4. Check the result

Return to Today and check whether the item is still waiting for you. Inspect the action result or [Activity](/docs/command-center/activity) for more context. A rejected action should not be treated as sent.

If a real action fails or its outcome is unclear, inspect its status before submitting another request. [Receipts and audit](/docs/start/receipts) explains how to tell a confirmed result from unfinished work.

## Continue with your own work

Use [Conversations](/docs/conversations/reply) to answer a customer, [Pipeline](/docs/pipeline/board) to update a deal, and [Inbox](/docs/command-center/inbox) to triage new intake. You can return to Today between tasks.

Before using real data, follow [Setup Center](/docs/workspace/setup). The demo shows the workflow; it does not verify your provider connections.

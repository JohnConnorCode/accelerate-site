Open `/admin/settings` to manage notification preferences and the configuration exposed to your account.

## Change one setting

1. Find the setting and read its description. Confirm the current workspace before editing.
2. Change the value or notification preference using its control.
3. Save if the control provides a save action. Wait for the request to finish before making another change.
4. Reload the page and confirm the saved value. For a notification preference, check the next relevant event before assuming delivery works.

Notification categories include new inquiries, hot leads, proposal views, overdue tasks and expiring contracts. A preference controls which notifications are requested; delivery also depends on the relevant connection and service.

## Choose or create an appearance

Open the appearance control in the workspace navigation to choose Paper, Night,
Signal, Studio or Frost. The preference stays on this device. Colors, corners,
controls and dialogs follow the selected theme together.

Choose **Create a theme** to open **Branding**. Start from an existing appearance,
then adjust its palette, typography, corners and depth. The preview shows your
edits before they affect the workspace. Choose **Save and use theme** to save the
workspace definition and select it on this device. Other members can select the
saved theme from their appearance control.

You can also describe a style under **Create with AI**, such as “warm ivory with
forest green accents.” With the workspace AI connection configured, the assistant
prepares a branding proposal for review. Check the exact proposed change and
approve it before it saves; normal model usage costs apply. Select the saved
workspace theme in Appearance to use it. The fictional demo does not call a paid
model. Manual editing and importing work without an AI connection.

**Import or export a theme** lets you reuse a JSON definition between workspaces.
Import previews the definition; it does not save it. Invalid fields and text
contrast below 4.5:1 are rejected. Adjust the named colors and try again. One
custom workspace theme is stored at a time; export a design before replacing it
if you want to keep a copy. **Reset edits** restores the saved branding. If another
person saves first, reload and review their version before applying your edits.

## Connect a provider

Use [Integrations](/docs/workspace/integrations) for provider credentials and connection setup. General settings reject values that resemble secrets. If a credential field is missing, follow the connection guide rather than placing the key in a text setting.

## Recover from a failed save

Reload to check the stored value. If it stayed unchanged, record the setting name and error for your technical owner. Do not include the value when it contains private business information.

Use [Setup Center](/docs/workspace/setup) to inspect a connection problem and [Activity](/docs/command-center/activity) to investigate who changed configuration.

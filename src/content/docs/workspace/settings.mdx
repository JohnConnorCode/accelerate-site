---
title: "Settings"
description: "Notification preferences and the configuration that powers the operating system."
updated: "2026-09-04"
---

Open `/admin/settings`. Notification preferences and operating configuration live here. Values that look like secrets are rejected; credentials belong on [Integrations](/docs/workspace/integrations).

Changing a setting writes an audit row without storing the value in the ledger. Layout customization for Today is a layout document per tenant.

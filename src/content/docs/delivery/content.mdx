When next month's editorial plan is spread across conversations and notes, the team spends time rebuilding what is ready and who owns it. The **Content Calendar** keeps each item and its publishing stage in one board or list, so the next piece of work stays visible. Ask AI reads that same calendar and can prepare item creation, edits, deletion and moves for your review when the Content module is enabled.

## Create and track an item

1. Select **New Content** and enter the details available in the form. Give the item a title that identifies the piece, such as “September customer onboarding email”.
2. Save it and confirm it appears in the expected column.
3. Open the item to update its details. Clear an optional field, such as Notes, when that information should be removed, then select **Update**. Move the item when the work has reached the next stage.
4. Switch to list view if that makes the queue easier to review. Reload after a change to confirm it persisted.

## Remove a calendar item

Open the item, select **Delete content item**, and confirm **Delete** when the item should be permanently removed from this calendar. Approval history and audit receipts remain available, so removing the brief preserves the record of what happened. Keep the publishing destination open when you also need to change a live page.

## Ask AI about the calendar

Open **Ask AI** from Today or **AI Workspace**. Ask for items by status or category, such as “List the draft items in the automation category.” The assistant reads the five most recently added matching items and says when more results match. Ask it to create a new item, edit an existing one, delete a named item, or move up to ten named items between existing columns. For example, Northline Roofing can ask, “Create a draft called Storm-season roof inspection checklist, with Evan Cole as the author.” The assistant prepares an exact preview and stages a proposal; open **Approvals** in Work to inspect the title, details, affected items and deletion consequence before deciding.

Calendar lifecycle commands keep human approval. If you revise the request or another person changes an item or column, request a fresh preview and approve the new proposal. The original review cannot authorize different content. Creation, deletion and moves return a receipt after the calendar and audit record commit together. Brief creation, item changes and website publication remain separate steps. You can also ask it to prepare a grounded brief from a title and optional keywords or category; the brief is working copy you can review before adding it to the calendar. Brief generation needs an AI provider configured for the workspace.

An MCP assistant connected through the workspace administrator’s OAuth connection can use the same calendar preview and proposal tools. Review the staged calendar change in **Approvals** as a workspace administrator, because the connection can prepare the change while the saved result uses your current administrator access.

The board scrolls across columns, and each column has a button for keyboard navigation. Opening and closing an item keeps your place, and a refresh retains the visible work while it reloads.

## Review a generated draft

Check names, dates, prices, statistics and source links against the material used for the brief. Replace unsupported claims before publication, then add the reviewed brief to the calendar when it is ready to track.

To prepare an email distribution, continue with [Email Studio](/docs/outreach/email-studio).

## What to check

- A calendar status tracks editorial progress. Check the publishing destination to confirm a page is live or a campaign was sent.
- When Ask AI reports more than five matches, use the Content Calendar filters to inspect the remaining items.
- After an interrupted response, reload and inspect the calendar before creating another item. Retrying an open create or delete request uses its saved receipt; an integration should keep the same request key for that retry.
- If an item or column changed during review, refresh the calendar and prepare a new proposal against its current state. A failed batch reorder saves none of its moves.
- Check that the workspace is active, your administrator membership is current, and Content is enabled when a save is refused. Deletion is permanent, so recreate the calendar item through a new reviewed request if it was removed by mistake.
- The demo uses fictional session-local calendar records and simulated approvals. Use a configured workspace to test live assistant selection and database persistence.

## Start the work

Use the [client onboarding recipe](/docs/recipes/engagement-onboarding) to turn a won opportunity into an assigned checklist. The [Clients guide](/docs/delivery/clients) also explains the built-in delivery handoff, its engagement record and partial-result recovery. Choose the flow that matches the work you intend to create so the team keeps one clear set of commitments.

## Coordinate the ongoing operation

[Bookings](/docs/delivery/bookings) helps you review scheduled conversations and record their outcome. [Content](/docs/delivery/content) tracks editorial briefs and publishing stages. [Resource Downloads](/docs/delivery/resources) shows who requested a file and when, so the team can inspect the related contact before following up.

## What to check

Check each source record and saved result before treating a handoff as complete. Task creation starts the delivery process; the assigned work still needs to happen. An editorial status records progress, while the publishing destination confirms that a page went live. Resource Downloads lists requests and is separate from a resource publishing tool.

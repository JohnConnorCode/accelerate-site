Use Email Studio to prepare reusable copy, investigate a send or write a direct follow-up. Open **Email Studio** at `/admin/emails`, then choose Templates, History or Composer for the task at hand.

## Templates

Drafts stay protected until you explicitly publish a revision, and preview and test sends use the exact same rendering path as production, so a test that looks right in the composer is the template that will go out to a customer.

## History

Open a send to inspect its recorded status and provider receipt. Check the recipient, time and content before deciding whether to retry. A missing provider ID needs investigation; it does not establish delivery or prove that nothing was sent.

## Composer

Choose the recipient, write the message and review its exact content before sending. The shared sender checks communication eligibility and records an operation identity so retrying the same request can be reconciled. Inspect the resulting status in History. If the result is uncertain, investigate that send before creating another message.

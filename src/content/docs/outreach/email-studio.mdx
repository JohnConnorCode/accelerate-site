Open **Email Templates** at `/admin/emails` to prepare reusable copy or investigate a send. Choose **Templates** or **Sent history**. To write a direct follow-up, open a template and select **Compose**.

## Templates

Drafts stay protected until you explicitly publish a revision, and preview and test sends use the exact same rendering path as production, so a test that looks right in the composer is the template that will go out to a customer.

## History

Open a send to inspect its recorded status and provider receipt. Check the recipient, time and content before deciding whether to retry. A missing provider ID needs investigation; it does not establish delivery or prove that nothing was sent.

History combines operator sends and canonical message receipts using their recorded send times. If one source cannot be read, the available records remain visible with an incomplete-history notice. If neither source can be read, the screen shows an error and retry instead of an empty history.

## Composer

Select **Compose** on an open template, then choose the recipient and review the message before sending. The shared sender checks communication eligibility and records an operation identity so retrying the same request can be reconciled. Inspect the resulting status in **Sent history**. If the result is uncertain, investigate that send before creating another message.

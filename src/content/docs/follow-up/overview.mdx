Inbound capture always writes the inquiry, the canonical records, the activity receipt, and an operator task before it attempts an automated reply. A mail or model outage cannot drop the lead. Use this page after [your first result](/docs/start/first-value).

## Starting screen

Open **Today** at `/admin/today`, or **Inbox** at `/admin/inbox` with the Tasks filter. Website forms set the next action to `Reply to new inquiry`. Chat sets `Reply to new chat inquiry`. A lead created with **New Lead** sets `Qualify manually created lead`.

## Required input

You need the opportunity open long enough to see the person, the next action, and **Verified activity**. Completing the task needs no extra form fields. Sending a real reply later needs a verified Resend (or Google) connection, which this page does not assume.

## Ordered actions

1. Open the task or the linked opportunity.
2. Confirm **Verified activity** already contains the capture receipt (**Website inquiry captured**, **Chat inquiry captured**, or **Manual lead captured**).
3. Do the human follow-up outside the product, or from **Conversations** if mail is connected.
4. On Today, choose **Complete task**. Use **Snooze until tomorrow** when the commitment should wait.
5. Re-open the opportunity and **Activity** at `/admin/activity` to confirm the completion receipt.

## Saved result

The task is no longer open. The opportunity still holds the next-action text until someone changes it on the record. The activity ledger keeps both the capture receipt and the task-completion receipt. Repeating the same inbound source id does not create a second capture activity.

## Recovery

- No capture receipt: treat the inquiry as unfiled. Check **Identity Review** if the email is ambiguous.
- Task already completed: do not complete a lookalike task for the same opportunity; the inbound dedupe key is `inbound-follow-up:{opportunity id}`.
- Automated reply did not send: that is expected without an approved responder policy and a mail provider. The records and task still exist.
- Duplicate open opportunities for one email: stop. Resolve **Identity Review** before creating another lead.

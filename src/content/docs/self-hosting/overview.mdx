The Command Center is MIT licensed. Clone it, connect your own Supabase project, and run the same codebase. You own the code, the database, and any AI provider key you connect.

## What you need

Someone on your team should be comfortable with a terminal and a database. The managed path exists for teams without that person.

- Node 22 or later
- A Supabase project (URL plus anon and service-role keys)
- An OpenRouter key for AI operations, and a Resend key for email

## Start it locally

Clone the repository and install dependencies, then create a `.env.local` file with your Supabase URL, Supabase keys, founder email, and site URL. Run the ordered migrations, then start the development server.

## What you get

CRM, pipeline, inbox, campaigns, proposals, and analytics in one application, with AI operations behind approval gates and an audit trail, using your own provider keys. Nothing phones home to us.

Self-host now and add managed execution when the business needs it: configuration around your existing tools, migrations and monitoring handled for you, and training for your team. The contact page is the way to start that conversation.

An opportunity value, a client agreement and a collected payment describe different parts of the business. **Revenue** shows recorded client and proposal values alongside a separate opportunity summary, so you can inspect where a figure comes from before using it to make a decision.

## What the figures mean

| Figure                    | Source in the current application                                   |
| ------------------------- | ------------------------------------------------------------------- |
| Open pipeline value       | Current open opportunities and their stored values                  |
| Weighted value            | Current opportunity values weighted by their recorded probabilities |
| Won revenue               | Values on opportunities recorded as won                             |
| Monthly recurring revenue | Monthly values on active client records                             |
| One-time value            | One-time amounts recorded on client records                         |
| Average client value      | Active-client monthly total divided by active-client count          |
| Industry breakdown        | Active-client monthly values grouped by industry                    |
| Accepted proposal value   | Monthly totals on accepted proposals                                |
| Churned share             | Churned records as a percentage of current non-onboarding clients   |

The **Opportunity values** summary keeps opportunity figures separate from client and proposal values. A won opportunity describes the recorded sales outcome; verify payment through the relevant provider evidence when you need collected cash.

**Active Contracts by Start Month** groups the contracts active today by their start month in UTC and accumulates their monthly values. Contracts that share a month appear as one point, and the final value agrees with Monthly Recurring. Onboarding, paused and churned contracts are excluded from this active total.

When a valid start date is missing, the chart uses the creation date and tells you how many contracts used that fallback. If both dates are unavailable, their value remains in a final **Date unavailable** point, so missing dates never silently reduce the total.

**Churned Share** describes the current client records across all recorded dates, excluding onboarding records from its denominator. Use it to inspect the mix of client statuses; a period churn calculation needs dated departures and the client base at the beginning of that period.

## Example: check a changed client agreement

In the fictional Northline Roofing workspace, open [Clients](/docs/delivery/clients) and check an active agreement’s monthly value and contract start. Open Revenue and compare that agreement with **Active Monthly Value by Client**, then check the final chart value against **Monthly Recurring**. After a simulated change marks that client churned, its monthly value leaves both active totals because the report reflects the clients active now.

## Investigate a difference

1. Identify the figure and the records included in it. Compare monthly value with monthly value; keep one-time amounts separate.
2. Open the relevant [client](/docs/delivery/clients) or [proposal](/docs/proposals) and check status, amount and dates against the agreement.
3. Compare with [Pipeline](/docs/pipeline/board) only after checking what that view counts. An opportunity amount, a client agreement and an accepted proposal can represent different stages of the same business.
4. Correct a demonstrated source-record error through its supported edit flow, then reload Revenue.

## What to check

If Revenue cannot read every required source, it shows an error with **Retry**. A failed refresh keeps previously loaded figures visible with a warning, so retry successfully before treating those figures as current. A complete empty report shows zero and an empty client breakdown.

If retry keeps failing, check Setup and ask the workspace owner to inspect reporting access or the read limit. The current report reads up to 5,000 records from each client, accepted-proposal and opportunity source; larger or incomplete reads show unavailable instead of partial totals.

Use this chart to understand the start months of today’s active agreements, and check a dated revenue or payment ledger when you need historical results. Confirm collected cash through provider receipts. If source records are correct but a figure differs from its stated calculation, report the expected formula and example record IDs to your technical owner before editing those records.

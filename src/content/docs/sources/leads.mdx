`/admin/leads` is website and form submissions. `/admin/chat-leads` is public-assistant handoffs. Both are intake. Qualification happens here. Promotion into [Contacts](/docs/contacts) is a review step.

Export exists for operators who still need a CSV. The live list is the source of truth; the file is a snapshot.

A chat lead that already matches a canonical email should be linked, not duplicated. Ambiguous matches wait.

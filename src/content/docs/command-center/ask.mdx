Ask AI can help you find business context and prepare the next step. Open it from Today or use the [AI Workspace](/docs/intelligence/workspace). The answer depends on the records, tools, and connections available to your workspace.

## Start with a specific question

Give the assistant a clear target and the result you need. For example:

- “What needs my attention today?”
- “Show the recent timeline for this contact.”
- “What is the next action on this opportunity?”
- “Draft a follow-up for this conversation, using the latest reply.”

Choose the relevant record when the interface provides context. Resolve an ambiguous person or company before asking for a change.

## Check the evidence

Read the supporting tool results or record links. If the answer is partial, inspect what was unavailable rather than treating the missing information as a fact. A disconnected provider or unavailable tool can limit what the assistant can answer.

## Review proposed work

A request to draft or change something can produce a proposal. Inspect its target and content in [Approvals](/docs/command-center/approvals). A generated draft does not prove that a message was sent.

After authorizing an action, check its result. If the assistant could not complete the request, use the visible reason to decide whether to reconnect a provider, narrow the question, or finish the task manually.

## Explore the tool reference

[AI tools](/docs/intelligence/tools) lists registered tools, connection requirements, and input schemas. Developers can follow [Add an AI tool](/docs/extend/tools) to extend the registry.

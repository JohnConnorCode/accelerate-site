## Ask something specific

A clear target and a clear result you need beats a vague prompt every time. Some real shapes that work well:

- "What needs my attention today?"
- "Show the recent timeline for this contact."
- "What is the next action on this opportunity?"
- "Draft a follow-up for this conversation, using the latest reply."

Choose the relevant record when the interface offers you that context, and resolve an ambiguous person or company before you ask for a change, so the assistant isn't guessing which one you meant either.

For recurring billing, Ask AI can explain only the current workspace records and registered capabilities. Stripe remains the payment authority. Use the customer account for checkout, invoices, payment details, cancellation, and plan changes; the assistant cannot charge or change a subscription unless a registered tool explicitly offers that action.

## Checking the evidence

Read the tool results or record links behind an answer before you act on it. If the answer is partial, look at what was unavailable rather than treating a gap as a fact the assistant confirmed; a disconnected provider or an unavailable tool can limit what it's able to answer, and the honest response to that is telling you it doesn't know, not guessing.

## Reviewing anything it proposes

A request to draft or change something can produce a proposal, which you can inspect in [Approvals](/docs/command-center/approvals). For a specific outreach request, such as emailing a customer about a proposal, Ask AI can prepare the email proposal during the same conversation. Open **Work → Approvals** to inspect the recipient and exact message. Once the assistant stages a proposal, it reports that status; after you approve it, check the execution receipt to learn whether the message was sent. If no proposal appears, inspect the run before repeating the request, because a partial run may have staged other work.

## What to check

- [AI tools](/docs/intelligence/tools) lists every registered tool, what it needs to be connected, and its input schema, if you want to see the full capability behind an answer.
- Developers extending the registry with a new tool should read [Add an AI tool](/docs/extend/tools).

Browse capabilities by the business area you want to improve: customers, sales, delivery, billing, marketing or custom Apps and AI. Each entry explains the practical purpose and current behavior. The reference uses the same catalog as the product's feature pages.

For a complete task, use an [industry recipe](/docs/recipes). For the exact registered operations an assistant can call, use the [AI tool reference](/docs/intelligence/tools).

Core records, optional Apps, connected providers and source extensions have different setup requirements. Check [Setup](/docs/workspace/setup) and [Integrations](/docs/workspace/integrations) for your installation before planning connected work.

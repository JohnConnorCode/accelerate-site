Use this reference when you know the kind of work you need to do and want to find the supporting capability. Each entry explains its business purpose and current behavior. The catalog is generated from the same content as the product page.

Entries marked **Review workflow** use an approval process. Other entries may still have permission, provider or policy requirements, so check [Setup Center](/docs/workspace/setup) and [Integrations](/docs/workspace/integrations) for your workspace’s availability.

For a complete task combining several capabilities, choose an [industry workflow recipe](/docs/recipes). For the exact operations an assistant can call, use the [AI tool reference](/docs/intelligence/tools).

### Media performance rules

- Card and case media are served from local optimized assets.
- The work index preloads only its first image.
- Below-fold images use the framework's responsive lazy loading.
- Northern Trust videos show local poster frames and make no third-party video request before interaction.

## Never publish

- Nice Right generic 290%, 12×, or generic 80% homepage claims.
- Unapproved SuperDebate invitation totals or live feature counts.
- Sparkblox's former 30% user-satisfaction claim.
- Any revenue estimate derived from WORK+SHELTER's time reduction.
- Testimonials or invented client attribution.

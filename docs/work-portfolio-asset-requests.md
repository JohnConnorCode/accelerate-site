# Selected work asset request list

This is the replacement-media checklist for the public portfolio. The current
implementation uses verified first-party or archived media and honest diagrams;
the files below would raise fidelity without changing the case-study architecture.

2026-08-25 fulfillment note: the founder supplied current WORK+SHELTER customer
site, quote-flow, and command-center captures plus current SuperDebate public
product and command-center captures. They are integrated as first-party evidence.
Sparkblox is no longer live; keep its case archival and use no new live-site
dependency.

## Delivery standard

- Send original PNG, JPG, WebP, MP4, or WebM files rather than screenshots of a
  social post when possible.
- For wide stills, 2400 px or more on the long edge is ideal. Preserve the
  original crop; the site creates responsive derivatives.
- For UI, include full-window exports with readable text. Remove customer names,
  email, financial data, private messages, credentials, and internal-only URLs.
- For motion, short muted WebM/MP4 loops plus one poster frame are ideal. Do not
  bake controls or social-platform chrome into the video.
- Put source files in the matching `public/work/<slug>/` directory or provide a
  folder named by project. Existing production paths can be retained when a
  supplied file is a direct replacement.

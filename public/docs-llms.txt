# Accelerate Documentation
> Practical guides for working with Accelerate and running the Command Center.

## Start
Learn the essentials and try your first complete workflow.

- [Start using Command Center](https://www.acceleratewith.us/docs/start/overview) (updated 2026-09-05): Choose a task, follow its steps and check the result.
- [For business owners](https://www.acceleratewith.us/docs/start/business-owners) (updated 2026-09-05): Choose a useful first workflow, assign ownership, and measure whether it helps.
- [For agencies](https://www.acceleratewith.us/docs/start/agencies) (updated 2026-09-05): Onboard client workspaces, verify access, and agree an operational handoff.
- [Your first workflow](https://www.acceleratewith.us/docs/start/daily-path) (updated 2026-09-05): Try the daily queue and review a proposed action using fictional data.
- [Core concepts](https://www.acceleratewith.us/docs/start/core-concepts) (updated 2026-09-05): The people, records, work, and decisions you will see in the workspace.
- [Your workspace](https://www.acceleratewith.us/docs/start/workspace) (updated 2026-09-05): Check your business context, membership, and available features.
- [Modules](https://www.acceleratewith.us/docs/start/modules) (updated 2026-09-04): Optional capabilities a workspace turns on and off without forking the app.
- [Check an action result](https://www.acceleratewith.us/docs/start/receipts) (updated 2026-09-05): Tell a prepared draft, an approved request, and a completed action apart.
- [Troubleshooting](https://www.acceleratewith.us/docs/start/troubleshooting) (updated 2026-09-05): Recover from common setup, access, search, and action failures without guessing.

## Command Center
One shared operating layer for the businesses that need it, and how to run the daily workspace.

- [The Command Center](https://www.acceleratewith.us/docs/command-center/overview) (updated 2026-09-05): Customer context, daily priorities, and reviewed actions in one workspace.
- [Capability reference](https://www.acceleratewith.us/docs/command-center/capabilities) (updated 2026-09-05): Explore capabilities and check their availability in your workspace.
- [Work the Today queue](https://www.acceleratewith.us/docs/command-center/today) (updated 2026-09-05): Review urgent work, take the next action and confirm the result.
- [Inbox](https://www.acceleratewith.us/docs/command-center/inbox) (updated 2026-09-04): Triage leads, messages, tasks, and staged actions that still need a person.
- [Review and approve actions](https://www.acceleratewith.us/docs/command-center/approvals) (updated 2026-09-05): Understand what waits for review, what approval does, and how to check the result.
- [Inspect activity](https://www.acceleratewith.us/docs/command-center/activity) (updated 2026-09-05): Find a recorded change and trace it to the affected record.
- [Ask AI](https://www.acceleratewith.us/docs/command-center/ask) (updated 2026-09-05): Ask a specific question, inspect the evidence, and review any proposed action.

## Build on it
For coding agents and humans: add a module, an integration adapter, a plugin, or an MCP client without forking core.

- [Extend the runtime](https://www.acceleratewith.us/docs/extend/overview) (updated 2026-09-04): What every extension inherits: approval, audit, module gating, and MCP.
- [Your first developer change](https://www.acceleratewith.us/docs/extend/first-change) (updated 2026-09-05): Run the demo, find the important files, and make a small extension change.
- [Add a module](https://www.acceleratewith.us/docs/extend/modules) (updated 2026-09-04): Register a JSON manifest and pages. Nothing in extensions/ is executed.
- [Add an integration adapter](https://www.acceleratewith.us/docs/extend/adapters) (updated 2026-09-04): Verify credentials, encrypt them, and turn inbound events into canonical records.
- [Plugins](https://www.acceleratewith.us/docs/extend/plugins) (updated 2026-09-06): Register a plugin manifest with tools and triggers that still go through governance.
- [Add an AI tool](https://www.acceleratewith.us/docs/extend/tools) (updated 2026-09-04): Register a schema, an impact tier, and a service boundary. Mutating tools propose.
- [MCP concepts](https://www.acceleratewith.us/docs/extend/mcp) (updated 2026-09-04): Bounded reads, staged writes, tenant isolation. The same registry the UI uses.
- [Connect an MCP client](https://www.acceleratewith.us/docs/extend/mcp-clients) (updated 2026-09-05): Connect an external assistant to the intended workspace and verify a read first.
- [Inbound webhooks](https://www.acceleratewith.us/docs/extend/webhooks) (updated 2026-09-04): Tenant-scoped public routes, signature checks, replay windows, and canonical ingest.
